* Org2
#+attr_html: :width 100px
[[./logo.png]]

A from-scratch successor to Org Mode, built to be editor-agnostic and platform-agnostic.

Reference: https://avi.press/posts/2024-01-15-standalone-org.html

** Status (honest version)

Org2 is *early alpha*.

- Best-supported workflow today: CLI + VS Code
- Core parsing/planning flows work well enough for daily use
- APIs and command flags may still change
- Not yet a full GNU Org Mode replacement

** What’s working now

- Core Org structures: headings, drawers/properties, links, planning lines, TODO states
- Agenda workflows (CLI + VS Code)
- Basic editing workflows (TODO/planning updates, archive/refile, capture)
- HTML export (MVP)
- LSP server (MVP) for links/navigation/completions/formatting

** What’s not done yet

- Full Org Mode parity
- Mature recurring/habits/clocking ecosystem
- Stable plugin ecosystem
- Broad editor parity beyond VS Code

** Quick start

#+begin_src sh
cd /path/to/org2
npm install
npm run build
#+end_src

Run CLI from source:

- =npm run org2 -- <command> [...args]= (recommended)
- =node dist/cli.js <command> [...args]=

Discover current commands/flags:

#+begin_src sh
npm run org2 -- --help
npm run org2 -- agenda --help
#+end_src

** Common CLI usage

Agenda on a directory:

#+begin_src sh
npm run org2 -- agenda --dir /path/to/org --recursive
#+end_src

Agenda on explicit files:

#+begin_src sh
npm run org2 -- agenda --files a.org b.org
#+end_src

Bounded range + JSON:

#+begin_src sh
npm run org2 -- agenda --from 2026-01-01 --to 2026-01-31 --format json
#+end_src

Run language server:

#+begin_src sh
npm run org2 -- lsp
#+end_src
