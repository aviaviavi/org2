#+TITLE: Architecture
#+SUBTITLE: A local-first workspace built on ordinary files and an open toolkit.

* The boundary

Celorga has two layers under one name.

The *Celorga app* is the native workspace, onboarding, integrations, and overall experience for building knowledge locally and putting it to work with people and agents.

The *Celorga runtime* is the independently specified compiler, CLI, and semantic Org profile underneath the app, together with its npm package, schemas, and editor tooling. Documents are ordinary =.org= files.

* Portability

- Ordinary =.org= files are the source of truth for documents.
- The command-line tools are =celorga= and =celorga-lsp=; =org2= and =org2-lsp= remain compatibility aliases.
- The npm package is =celorga= (releases before the rename were published as =@aviaviavi/org2=).
- VS Code, Vim, Neovim, Emacs, CLI JSON, and MCP clients can work with the same corpus.
- Agent runs, workflows, approvals, citations, and provenance are inspectable corpus records.
- Any configured local, remote, hosted, or self-hosted agent can participate above the deterministic Celorga runtime.

* What the Celorga app adds

- A native Mac workspace for capture, Agenda, files, meetings, agents, and review.
- A five-minute first-run path from a folder to a cited agent result.
- Clear approval boundaries for consequential actions.
- Local configuration of agent destinations and explicitly authorized context.
- Packaging, updates, diagnostics, and a coherent product experience.
