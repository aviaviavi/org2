* Memory that drives work

Most second brains stop at storage and retrieval. Org2 connects durable knowledge to the work it informs: agendas, meetings, cited answers, data, goals, agent runs, and approvals. Results flow back into the same corpus instead of disappearing into separate apps and chat histories.

Your files remain the source of truth. Apps and agents share the context, humans keep clear review boundaries, and changing a model or tool does not mean starting over.

* What you can do with it

- *Plan and track work* from TODOs, deadlines, meetings, decisions, and linked context.
- *Build personal or team memory* that people can read and agents can cite.
- *Ask grounded questions* across notes, sources, tasks, data, and prior agent work.
- *Coordinate multiple agents* in one attributed, corpus-grounded conversation.
- *Connect reports to evidence* with local data, queries, tables, charts, and provenance.
- *Publish when useful* from the same source tree you use privately.

* Private-by-default agent collaboration

A useful agent workspace needs precise sharing boundaries. Org2 keeps files local by default and can encrypt individual subtrees to you, a device, or a specific agent key. Encrypted notes remain ordinary files that can sync through Git, iCloud, Syncthing, or any transport you choose.

* How it works

Org2 reads ordinary =.org= and =.org2= files and compiles their tasks, links, dates, properties, provenance, and agent boundaries into one shared semantic model. The Mac and iOS apps, CLI, VS Code, Codex, and OpenClaw all work from that same source-backed context.

The result is deliberately boring composability: inspectable files that can drive daily planning, agent workflows, data views, and publishing without locking the work into one application.
