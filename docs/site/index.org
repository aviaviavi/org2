#+TITLE: Every AI agent you use. One workspace you own.
#+SUBTITLE: Celorga is an open-source control plane for AI agents, built for knowledge work instead of code. Run Claude Code, Codex, OpenCode, and local models side by side on your notes, tasks, meetings, and data, and approve what matters from your desk or your phone. Everything they read and write is a plain-text file you own.

<section class="celorga-home-story" id="home-agents" aria-labelledby="home-agents-title">
  <div class="celorga-home-story-copy">
    <h2 id="home-agents-title">Put all your agents in one room.</h2>
    <p>Mention <code>@claude</code>, <code>@codex</code>, or a local model in the same thread. Compare their answers, or let one agent pass work to the next while you watch every step. Each keeps its own identity, model, and reasoning setting.</p>
    <ul>
      <li><strong>Agents hand off to each other.</strong> When one agent mentions another, that agent takes the next turn. A limit, four in a row by default, keeps them from looping until you reply.</li>
      <li><strong>Different access for different agents.</strong> Encrypt a note to one agent's key. The others only see what that agent chooses to hand off.</li>
      <li><strong>Shared memory, no re-explaining.</strong> Every agent reads and cites the same notes, so context survives when you switch tools or models.</li>
    </ul>

      <li><strong>Activity.</strong> See what's running, on which machine, what's waiting on you, and why.</li>
      <li><strong>Keeps going when your laptop sleeps.</strong> A headless Celorga server can own agent turns and schedules, while your laptop and phone become clients.</li>

<section class="celorga-home-own" id="home-own" aria-labelledby="home-own-title">
  <div class="celorga-sample-intro">
    <h2 id="home-own-title">No lock-in. No database. Just files.</h2>
    <p>Your workspace is a folder of readable text files. Open them in any editor, keep them in Git, and switch apps or AI models without migrating anything. The agents you use today, and the ones you'll use next year, all read the same memory.</p>
  </div>
  <div class="celorga-feature-card-grid">
    <article><h3>Local by default</h3><p>Nothing leaves your machine unless you send it to an agent you configured or publish it. There's no account to create.</p></article>
    <article><h3>Open source</h3><p>The apps, runtime, and file format specification are Apache-2.0 licensed. Read the code, fork it, or extend it with plugins.</p></article>
    <article><h3>Sync your way</h3><p>Use iCloud, Git, Syncthing, or any folder sync. Share a workspace with teammates the same way.</p></article>
    <article><h3>Encrypt what's sensitive</h3><p>Encrypt a single section to yourself, a device, or one agent, and keep the rest of the file readable.</p></article>
    <article><h3>Edit anywhere</h3><p>Open the same files in VS Code, Vim, or Emacs, or script them with the Celorga command line.</p></article>
    <article><h3>Safe to automate</h3><p>Celorga's command line and built-in tools preview each change and apply it only when asked. Because everything is text, every agent edit is a readable diff.</p></article>
