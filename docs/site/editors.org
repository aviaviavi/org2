#+TITLE: Editors

Org2 is editor-agnostic. Today, VS Code has the most complete integration.

* VS Code

** Install

The extension currently lives in this repository at =editors/vscode-org2/=.

1. Build Org2 CLI and extension dependencies:

#+begin_src sh
git clone https://github.com/aviaviavi/org2.git
cd org2
npm ci
npm run build
#+end_src

2. Open =editors/vscode-org2/= in VS Code and run:

#+begin_src sh
npm ci
#+end_src

3. Install the extension from source:

- In VS Code: open Extensions panel, click menu (=...=), choose =Install from VSIX...= if you have a VSIX.
- Or run the extension in development via VS Code Extension Development Host from the repo.

4. Confirm =org2= CLI availability:

- Either use the repo-built fallback CLI,
- Or install/provide =org2= on your =PATH=.

For command behavior/settings details, see [[file:tooling-reference.org][Tooling reference]] and =editors/vscode-org2/README.md=.

** Keyboard shortcuts

This section is comprehensive for the current default bindings declared in =editors/vscode-org2/package.json=.

*** Direct bindings

| Linux/Windows | macOS      | Command ID                 | Action |
|---------------+------------+----------------------------+--------|
| ctrl+alt+t    | ctrl+alt+t | =org2.toggleTodo=          | Toggle TODO status |
| ctrl+alt+o    | ctrl+alt+o | =org2.toggleFoldHere=      | Toggle fold at cursor |
| ctrl+alt+d    | ctrl+alt+d | =org2.debugFoldingRanges=  | Debug folding ranges |
| j             | j          | =cursorDown=               | Visible-line down (only with VSCodeVim + =org2.vim.visibleLineNavigation=true=) |
| k             | k          | =cursorUp=                 | Visible-line up (only with VSCodeVim + =org2.vim.visibleLineNavigation=true=) |

*** Power keymap

When =org2.keymap.power=true= (default), prefix is:

- Linux/Windows: =ctrl+;=
- macOS: =cmd+;=

Then use the second key (or namespace chord) below.
