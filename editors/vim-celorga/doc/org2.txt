1. Overview                                              *org2-overview*

This plugin provides minimal Celorga support:

- Filetype detection for *.org2
- Syntax highlighting
- Folding by heading level

The plugin directory and the 'org2' filetype keep their names for
compatibility. The pre-rename :Org2* commands and |g:org2_format_on_save|
option still work as aliases of the :Celorga* commands and
|g:celorga_format_on_save|.


2. Folding                                                *org2-folding*

The plugin sets:

  foldmethod=expr
  foldexpr=org2#foldexpr(v:lnum)

Normal mode mapping:

  <Tab>    Toggle fold for the current item.

If the cursor is not on a heading, <Tab> will use the closest heading above.


3. Syntax                                                  *org2-syntax*

Headings are highlighted with separate syntax groups per level:

  org2Heading1 .. org2Heading8

These are linked to common Vim highlight groups by default.


4. Commands                                              *org2-commands*

These commands run the 'celorga' CLI when it is on your PATH and fall back
to 'org2', which remains a compatibility alias.

:CelorgaTodoToggle                                  *:CelorgaTodoToggle*
:Org2TodoToggle                                          *:Org2TodoToggle*
  Toggle the TODO keyword on the current headline.

:CelorgaTodoSet {status}                                *:CelorgaTodoSet*
:Org2TodoSet {status}                                    *:Org2TodoSet*
  Set the TODO keyword on the current headline.

:CelorgaFormat                                          *:CelorgaFormat*
:Org2Format                                              *:Org2Format*
  Format the buffer with 'celorga fmt --stdin'.

The :Org2* commands are aliases kept for compatibility.

                    *g:celorga_format_on_save* *g:org2_format_on_save*
Buffers are formatted before each write unless you set: >
  let g:celorga_format_on_save = 0
<
g:org2_format_on_save, the pre-rename name, is used when
g:celorga_format_on_save is not set.
